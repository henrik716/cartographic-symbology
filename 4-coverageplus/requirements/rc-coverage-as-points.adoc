===== Symbolizer `mark` property

[requirement]
====
[%metadata]
identifier:: /req/coverage-as-points/mark
part:: An Encoding SHALL support defining a `mark` Symbolizer property as a Marker.
part:: A Renderer SHALL support portraying a coverage as individual points, as if it were a MultiPoint vector feature, by drawing the graphical elements of the `mark` at the location of each coverage cell.
part:: A Renderer SHALL support evaluating the Parameter Values of the `mark` for each coverage cell, so that the values of that cell can be used to style its marker (e.g., to orient a wind barb).
====

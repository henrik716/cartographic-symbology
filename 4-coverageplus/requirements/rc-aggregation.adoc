[[req-aggregation-aggregate]]
===== `Aggregate` function

[requirement]
====
[%metadata]
identifier:: /req/aggregation/aggregate
part:: An Encoding SHALL support defining a call to the `Aggregate` standard function taking an Expression to aggregate, an aggregation method, and an array of names of the dimensions to aggregate upon.
part:: A Renderer SHALL support evaluating the `Aggregate` function by evaluating the expression for every coverage cell along the specified dimensions (e.g., `time`) and combining the resulting values using the aggregation method, resulting in a single value for each remaining position.
====

[[req-aggregation-methods]]
===== Aggregation methods

[requirement]
====
[%metadata]
identifier:: /req/aggregation/methods
part:: An Encoding SHALL support specifying the aggregation method as one of `min`, `max`, `average`, `sum`, `first`, `last`, `median` or `stdDev`.
part:: A Renderer SHALL support combining the values using the minimum (`min`), maximum (`max`), arithmetic mean (`average`), sum (`sum`), first value along the dimension (`first`), last value along the dimension (`last`), median (`median`) or standard deviation (`stdDev`).
====

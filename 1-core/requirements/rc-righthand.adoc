===== Any right-hand operands

[requirement]
====
[%metadata]
identifier:: /req/right-hand/operands
part:: An Encoding SHALL support defining the right-hand operands of RelationExpressions using any type of Expression (e.g., Identifier Expressions or Function call Expressions), not only Literal Expressions.
part:: A Renderer SHALL support evaluating RelationExpressions whose right-hand operands are any type of Expression.
====

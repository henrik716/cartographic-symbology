[[req-geometry-manipulation-s-intersection]]
===== Geometry `s_intersection` function

[requirement]
====
[%metadata]
identifier:: /req/geometry-manipulation/s-intersection
part:: An Encoding SHALL support defining a call to the `s_intersection` standard function taking two Geometry arguments.
part:: A Renderer SHALL support evaluating `s_intersection(a, b)` as a Geometry representing the point set intersection of `a` and `b`.
====

==== Temporal Relation Functions

[[rc-table-temporal-relations]]

[requirements_class]
.Temporal Relation Functions
====
[%metadata]
identifier:: http://www.opengis.net/spec/cartosym-3/1.0/req/temporal-relations
inherit:: http://www.opengis.net/spec/cartosym-1/2.0/req/core
subject:: Style encodings and Renderers
====

In the following requirements, `a.start` and `a.end` denote the start and end of the first argument, and `b.start` and `b.end` those of the second argument.
A TimeInstant argument is treated as a TimeInterval whose start and end are both equal to that instant.
These definitions correspond to the temporal functions of OGC CQL2.

[[req-temporal-relations-t-after]]
===== Temporal `t_after` function

[requirement]
====
[%metadata]
identifier:: /req/temporal-relations/t-after
part:: An Encoding SHALL support defining a call to the `t_after` standard function taking two TimeInstant arguments or two TimeInterval arguments.
part:: A Renderer SHALL support evaluating `t_after(a, b)` to true if and only if `a.start` is later than `b.end`.
====
